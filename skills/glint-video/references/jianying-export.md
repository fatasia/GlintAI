# 剪映草稿导出(实验)

`pnpm glint jianying --project=p.json --video=out.mp4 [--music=x] [--out=dir]` → 草稿目录 + SRT。

## 分层原则(什么可编辑、什么烘焙)

| 层 | 剪映里的形态 | 可编辑度 |
|---|---|---|
| 镜头内动效(运镜/转场/图表/3D) | 烘焙进底片 | 仅整段变速/调色 |
| 镜头边界 | 底片按场景切段(source_timerange) | 变速/重排/删减 |
| 屏幕字幕 | 剪映文本轨(句级,词级时间戳对齐) | 内容/字号/颜色全开 |
| 音乐 | 音频轨(传 --music 时) | 音量/替换 |
| 旁白人声 | 留在底片 | 不拆(重建成本高) |

要「字幕可编辑」的正配是 `render --plate` 的无字幕底片 + jianying 草稿:文本轨承接全部字幕,底片干净。

## 诚实边界

- **未真机验证**(2026-10):草稿按公开的 draft_content.json 结构生成(µs 时间基/materials/tracks),剪映专业版打开若提示「升级草稿」属正常;若被拒,把剪映版本与报错发回仓库。
- **单向**:剪映打开后草稿会升级加密,不要读回改过的草稿;要改就重导出。
- 独立元素(logo/计数)画中画拆层未做;文本样式是简化默认(白字底部),在剪映里调。

## SRT

`pnpm glint srt --project=p.json` 随时可出句级 SRT(词级时间戳聚合,按标点断句;无词级时按字重比例插值)。中文一行 ≤20 字的断句规则在字幕渲染里已内置,SRT 继承。
