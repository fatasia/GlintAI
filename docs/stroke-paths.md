# 手绘与逐笔动画

在高级编辑的「画面 → 对象与关键帧 → 手绘与逐笔动画」中画一笔，确认加入镜头。每笔都是可编辑对象，使用当前播放头作为起笔时间；在对象列表选择后，可调整笔色、笔宽、起笔时间和绘制时长，修改可撤销。

- 支持标题、要点、定义、引用、比较、图解、图表及代码场景；图片、视频、HTML、Three 场景暂不支持。
- 每笔最多 400 个手绘采样点；一个镜头最多 20 个对象。手绘只记录线条，不模拟压力或真实毛笔。
- 工程仍受 Web 编辑器 100000 字符总量限制；加入或编辑路径后超限会拒绝本次修改，未加入的手绘草稿保留。
- 路径数据支持 `M/L/H/V/Q/C/S/T/A/Z` 命令的受限子集（绝对或相对坐标；圆弧 A 按 SVG 端点-圆心规则转为分段三次贝塞尔）。弧的两个标志位必须分别用 `0` 或 `1` 表示，不支持紧凑旗标写法；不接受 SVG 文件、标记或外部内容。每条数据最多 8192 字符、512 个展开后的段，显式及生成坐标绝对值不超过 10000。
- 路径按自身坐标画布等比缩放；起笔时间和时长均以镜头开始为零点。动画超出镜头末尾的部分不会出现，需调整镜长或绘制时长。
- 曲线按近似弧长逐步显现；预览和原生导出使用同一帧驱动曲线切分，不依赖浏览器 CSS 动画或播放顺序。

工程 JSON 保存线条、坐标画布、样式和时间；不需要额外素材文件。关闭画面标签后保留已加载的对象画布和未提交的手绘草稿，刷新前请确认加入镜头。

已验证的真实帧对照、移动端操作及 H.264 样片见[验收记录](../evidence/MOTION-02/stroke-path-20261027/acceptance.md)。本功能不是任意 SVG 导入、路径形变或完整 Canvas 动画编辑器。
