# 跨章节资源包

将多个独立 SceneScript 工程打成一个可校验的目录，素材按内容摘要去重。恢复后每个章节仍是独立工程和资源目录。

```sh
pnpm glint bundle-chapters --project=chapter-1/project.json --project=chapter-2/project.json --out=chapter-pack
pnpm glint inspect-chapters --dir=chapter-pack
pnpm glint restore-chapters --dir=chapter-pack --out=restored
```

- 目标目录必须不存在；恢复时先校验清单和素材摘要，再创建目录。
- 查看命令只读并校验每个素材，输出章节、镜头和资源引用数，以及去重前后字节数；内容不匹配时直接报错。
- 相同资产 ID 与版本必须具有相同字段和引用文件内容；不一致时先修正资产或使用新版本。
- 不接受缺失文件、符号链接或不安全的资源路径。单素材上限 256 MiB，展开资源总量上限 2 GiB，最多 100 个工程、5000 条资源引用。
- 这是工程迁移包，不会同步远程素材库或替代已批准角色版本的后续修改流程。

## Web 与客户端章节工作台

高级编辑中的「章节 · 独立工程」可将当前可编辑工程显式保存为本机章节快照，调整名称和顺序，再载入另一章继续编辑。载入前需确认，当前工程先备份到「全部作品」；备份失败不会替换编辑区，在途任务期间禁止切换。

章节列表仅保存在当前浏览器，最多 100 章、2 MB。修改后需手动更新快照；JSON 导入先预览确认，不覆盖同 ID 章节。导出的 JSON 包含工程、资料和素材引用，**不含素材文件**。跨章同版本资产比较的是定义，相同路径不证明文件内容相同。需要迁移素材时，使用上面的 CLI 章节包。
