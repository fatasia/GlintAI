# 运行模式

Glint 有三种运行形态，能力相同，差别在数据落点、网络行为与鉴权方式。三种模式共用同一渲染实现，工程与素材可相互拷贝。

| | 本地开发 | 公网部署 | 桌面应用 |
|---|---|---|---|
| 启动 | `pnpm --filter glint-web serve` | Docker（见 [部署](deployment.md)） | `apps/desktop` Tauri 壳 |
| 数据落点 | 本机数据目录 | 服务器磁盘，卷挂载持久化 | 本机用户数据目录 |
| 鉴权 | 无（仅本机回环） | HTTP Basic，用户名 `glint`、密码为 `GLINT_ACCESS_TOKEN`；未设强令牌时拒绝公网启动 | 无（单用户本机） |
| 模型连接 | 环境变量或页面设置 | 同左，密钥只存在服务端 | 同本地 |
| 费用归属 | 你自己的模型账号 | 部署者的模型账号 | 你自己的模型账号 |
| 渲染 | 本机 Chrome + FFmpeg | 容器内 Chromium + FFmpeg | 桌面内置渲染（无需装浏览器） |

## 数据与网络边界

- 密钥只保存在服务端（环境变量或 0600 本地设置文件），页面永拿不到明文；更换服务地址时必须重新输入密钥。
- 生成类请求直连你配置的模型网关；除模型地址与你显式填写的参考地址（如上传参考视频的来源 URL）外，Glint 不向其他地址发起请求，也无遥测。
- 预览与导出走同一份渲染代码，同一工程在三种模式下产物一致。
- 公网模式会把内容与生成额度暴露给能拿到令牌的人；`GLINT_PUBLIC_AUTH=0` 只适合受控网络。桌面模式不监听网络端口。

## 能力差异

桌面壳是纯 WebView + 本机 Node 渲染管线，不内嵌浏览器安装；自动更新通道尚未启用（见 [发行说明](release.md)）。本地与公网模式功能一致；公网模式额外要求强访问令牌。
