# Glint 设计语言 v1

Glint 所有界面工作都以本文为准，无论由哪个人或模型来做。它规定 Glint **长什么样、怎么交互、怎么验收**，目的是让任何模型照着做，都能做出一致、克制、专业的界面。

- 令牌源码：[apps/web/src/ui/tokens.css](../../apps/web/src/ui/tokens.css)（唯一的视觉数值来源）
- 组件：[apps/web/src/ui/](../../apps/web/src/ui/)
- 外壳：[apps/web/src/shell/](../../apps/web/src/shell/)、[app-navigation.css](../../apps/web/src/app-navigation.css)
- 自动门禁：`pnpm check:ui`（§9）
- 截图核对：`pnpm --filter glint-web exec tsx ../../scripts/capture-ui.ts`（§10）

与本文冲突时，以本文为准。修改本文需在文末「变更记录」登记改动与理由。

## 1. 定位与气质

Glint 是创作者长时间工作的**工作室**，不是营销落地页。界面要让作品成为主角，工具退到背景里。

| 要 | 不要 |
|---|---|
| 安静、克制、专业，像一张好用的工作台 | 炫技、花哨、像广告页 |
| 内容（画面、页面、片段）有颜色，界面本身低对比 | 大面积彩色块、渐变、霓虹、紫蓝「AI 风」 |
| 一个强调色，只标出「你在哪、选中了什么、主操作是什么」 | 多个强调色、每个按钮都高亮 |
| 信息密度适中：编辑区紧凑，首页舒展 | 处处卡片套卡片、处处边框 |
| 中文排版优先：标点、行高、混排都要讲究 | 照搬英文界面的字号和间距 |

界面取向（调研同类创作工具后的取舍）：
- 剪辑类：面板浮在更深一级的底板上；轨道按媒体类型固定颜色；画布、时间线、检查器三处选中联动。
- 设计类：首页采用「一个输入框 + 类型选择 + 示例」三段式；AI 面板可以伸缩，不永久挤占画布；先自动铺好草稿，再交给人精修。
- 语义色只用于文字、图标、细线，不用于大面积背景；长任务按阶段显示进度，不只用一个转圈。

我们不跟随「功能超市」式十几并列标签的信息架构。

## 2. 颜色

### 2.1 表面层级（暖中性灰，一个色系）

| 令牌 | 用途 |
|---|---|
| `--g-bg-0` | 底板：应用背景、导航栏、画布凹槽 |
| `--g-bg-1` | 面板：每个工作区的主表面 |
| `--g-bg-2` | 抬升：输入框、卡片、菜单、提示 |
| `--g-bg-3` | 悬停 |
| `--g-bg-4` | 按下、选中的底色 |

规则：用**相邻两级明度差**区分层次，不靠边框。面板之间露出一条底板缝隙，这就是分隔。边框只在需要时使用 `--g-line-1/2/3`。

### 2.2 文字

| 令牌 | 用途 | 对比度（深色，在 bg-1 上） |
|---|---|---|
| `--g-fg-1` | 正文、标题 | ≥ 12:1 |
| `--g-fg-2` | 次要说明 | ≥ 7:1 |
| `--g-fg-3` | 标签、元信息、占位说明 | ≥ 4.5:1 |
| `--g-fg-4` | 仅装饰与禁用状态，不承载必要信息 | — |

### 2.3 强调色：墨蓝

| 令牌 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--g-accent` | `#41649d` | `#2f4f86` | 主按钮底色、当前导航指示条、选中描边、播放头 |
| `--g-accent-hover` / `-press` | — | — | 主按钮悬停与按下 |
| `--g-accent-text` | `#93acd8` | `#2f4f86` | **用强调色写的文字**（链接、状态词），保证 ≥ 4.5:1 |
| `--g-accent-soft` | — | — | 选中项的浅底 |
| `--g-accent-line` | — | — | 焦点环、选中外框 |
| `--g-on-accent` | — | — | 主按钮上的文字 |

强调色只用于四件事：**主操作、当前位置、选中、焦点**。每个区域最多一个主按钮。文字一律用 `--g-accent-text`，不要直接用 `--g-accent` 当文字色。

### 2.4 语义色

`--g-ok`、`--g-warn`、`--g-danger` 及其 `-soft` 版本，只用于文字、图标、细进度条和浅底提示，不用来铺大面积背景。危险操作的按钮使用描边加危险色文字，而不是大红块。

### 2.5 时间线轨道色

轨道按媒体类型固定配色，用户不看标签也能分辨：`--g-track-scene / video / image / voice / music / sfx / caption`。轨道色不能和强调色混用；播放头使用 `--g-playhead`（即强调色）。

### 2.6 主题

深色和浅色由 `<html data-theme>` 显式切换并持久化。两套主题使用**同一组令牌名**；组件不得针对某个主题单独写颜色。

## 3. 字体与排版

- 字体：`--g-font`（Geist 负责拉丁字母与数字，系统中文字体负责中文：苹方 / HarmonyOS Sans / MiSans / 微软雅黑 / Noto Sans SC）；代码与时间码使用 `--g-font-mono`。
- 字号只用这 8 级：

| 令牌 | px | 用途 |
|---|---|---|
| `--g-fs-1` | 11 | 导航标签、微型标签 |
| `--g-fs-2` | 12 | 元信息、说明、提示 |
| `--g-fs-3` | 13 | **编辑区默认**：工具栏、列表、检查器 |
| `--g-fs-4` | 14 | 正文、输入框 |
| `--g-fs-5` | 16 | 区块标题 |
| `--g-fs-6` | 20 | 页面标题 |
| `--g-fs-7` | 28 | 空状态、对话框大标题 |
| `--g-fs-8` | 40 | 仅首页主标题 |

- 字重：400 正文，500 按钮与强调，600 标题。不用 700 以上，不用 300 以下。
- 行高：界面元素 `--g-lh-ui`（1.45），段落 `--g-lh-body`（1.65），大标题 `--g-lh-tight`（1.2）。
- 数字、时长、费用一律等宽数字（`.g-num` 或 `data-numeric`）。
- 标题使用 `text-wrap: balance`，段落使用 `pretty`，避免末行孤字。段落宽度不超过 60 个汉字。
- 不要全大写的英文小标题，不要中英混排的功能名（写「替换背景」，不写「new-background」）。

## 4. 间距、圆角、阴影、层级

- **间距**：4px 网格，`--g-sp-1`…`--g-sp-11`（2/4/6/8/12/16/20/24/32/40/56）。区块之间 24–32，组内 8–12，控件内 6–8。
- **圆角**：内小外大。`--g-r-1` 6（标签、内部小控件）、`--g-r-2` 8（按钮、输入框）、`--g-r-3` 12（面板、卡片）、`--g-r-4` 16（对话框、首页输入框）。
- **阴影**：只表示「浮起」：`--g-shadow-1` 用于控件，`-2` 用于菜单与提示，`-3` 用于对话框。选中状态用描边，不用阴影。
- **层级**：只用 `--g-z-base / sticky / dock / popover / dialog / toast`，不写数字。
- **控件高度**：`--g-control-h` 32，`--g-control-h-sm` 26。可点击区域不小于 32×32（触屏 44×44）。

## 5. 布局

### 5.1 应用外壳（已实现）

```text
┌──────┬──────────────────────────────────────────────┐
│ 导航 │  ┌────────────────────────────────────────┐  │
│ 栏   │  │ 区域顶栏（标题 · 标签）                  │  │  ← 素材 / 自动化 / 设置
│ 64px │  ├────────────────────────────────────────┤  │
│      │  │ 内容（在面板内部滚动，页面本身不滚动）    │  │
│ 项目 │  │                                        │  │
│ 素材 │  └────────────────────────────────────────┘  │
│ 自动化│        ↑ 面板浮在底板上，四周露出 6px 缝隙     │
│ ──── │                                              │
│ 剪辑台│                                              │
│      │                                              │
│ 帮助 │                                              │
│ 设置 │                                              │
└──────┴──────────────────────────────────────────────┘
```

- 导航栏：主导航（项目、素材、自动化）、工具（剪辑台），底部是帮助（文档、外观）和设置。当前项左侧有 3px 强调色指示条，图标切换为填充样式。
- 宽度 ≤ 820px 时，导航栏移到底部，成为标签栏。
- 每个位置都有 URL（`#/p/<id>`、`#/library/brand` 等）：刷新、后退、深链接都回到同一处。新增页面必须先在 [routes.ts](../../apps/web/src/shell/routes.ts) 登记路由。

### 5.2 工程工作区（目标形态，U-04/U-05/U-06）

```text
┌ 面包屑 · 工程名 ············ 画布｜时间线｜文档 ············ 版本 · 任务 · [导出] ┐
├ 大纲 240 ┬───────────── 主视图（画布 / 预览）─────────────┬ 检查器 ⇄ 助手 320–420 ┤
│ 资料      │                                              │ 选中对象的属性         │
│ 脚本      │                                              │ 或：助手（固定选择与   │
│ 角色/品牌 │                                              │ revision，可拖宽/收起）│
│ 镜头/页面 │                                              │                        │
├───────────┴──────────── 时间线坞（可折叠，多轨）───────────┴────────────────────────┤
└──────────────────────────────────────────────────────────────────────────────────────┘
```

- 一个工程只有**一块画布、一条时间线**。不再出现第二块「生成画布」或独立的「剪辑台」副本。
- 主视图永远最大；左右两栏都可以收起，宽度用 CSS 变量驱动，收起时主视图平滑变宽。
- 画布、时间线、检查器三处**选中联动**。
- 顶栏只有一个主按钮（导出）。保存是自动的，「创建版本」放在版本菜单里。

### 5.3 首页

一个输入框，加上创作类型（视频 · 演示稿 · 页面/原型 · 图片 · 短剧），再加 3–4 个示例起点，下方是最近工程网格（`auto-fill, minmax(260px, 1fr)`，封面 16:9，同一工程只出现一次）。导出格式不算创作类型。

### 5.4 工具页（素材、自动化、设置）

内容最大宽度 `--g-page-max`（1180px）居中。区域标签放在区域顶栏里，不另起一行标题。

## 6. 组件

先用现成组件，没有合适的再新建，新建的放进 `src/ui/` 并补到下表。

| 组件 | 用途 | 规则 |
|---|---|---|
| `Button` | 所有按钮 | `primary` 每个区域最多一个；`secondary` 默认；`ghost` 用于工具栏和次要操作。图标按钮必须有 `aria-label` |
| `.g-segmented` | 2–5 个互斥视图切换 | 不要用它承载导航 |
| `Tooltip` | 补充说明 | 只放补充信息，不能是唯一的标签；悬停 450ms 后出现 |
| `.g-popover` | 轻量弹层（帮助、筛选） | Radix Popover，Esc 关闭，焦点回到触发按钮 |
| 对话框 | 必须打断才能继续的确认 | 优先就地编辑、侧滑面板；不要什么都弹窗；不使用 `window.alert` |
| 空状态 | 没有内容时 | 一句话说明 + 一个可执行的下一步（例：「未配置图片模型 → 在此配置」） |
| 加载 | 等待 | 结构骨架屏；超过 2 秒显示阶段文字；可以取消的必须提供取消 |
| 错误 | 失败 | 就地显示：原因 + 下一步。不展示堆栈、环境变量名或内部 ID |

图标：使用 [ui/icons.tsx](../../apps/web/src/ui/icons.tsx) 的 Phosphor 线性图标（常规 / 填充两种字重），尺寸 16 或 20，不混用其他图标库。新增图标的方法见文件头注释。

## 7. 交互规则

1. **路由即状态**：每个视图都有地址；刷新、后退、深链接回到同一对象、视图和视口。
2. **一种保存**：自动保存，加上命名版本。不出现四种保存说法（「保存项目 / 已自动保存 / 共享 r0 / 版本 0」只保留一种）。
3. **一种选择**：画布、时间线、文档共享选中状态。助手发送时固定当时的选择和 revision。
4. **一种撤销**：跨视图、跨编辑器，包括助手和 Agent 做的修改；每一步都能查看差异。
5. **先报价再执行**：付费或耗时超过 10 秒的操作，执行前显示影响范围、费用和预计时长；执行中可以取消；结果进入任务中心。
6. **工具随上下文出现**：有选中对象才出现相关工具。不要成排的禁用按钮；必须禁用时，悬停说明原因。
7. **离开保护**：有未保存草稿时，切换工程或关闭页面前先拦截。所有导航都要经过 `authoring-leave` 守卫。
8. **键盘**：所有操作都可以用键盘完成；Tab 顺序与视觉顺序一致；Esc 关闭最上层；`Ctrl/⌘+K` 打开命令面板（U-08）；快捷键统一登记。
9. **反馈时间**：100ms 内给出按压反馈；1 秒内显示进行中状态；超过 10 秒显示阶段和可以取消。
10. **破坏性操作**：可以撤销的直接执行并给出撤销提示；不可撤销的才弹确认，确认按钮写明动作（「删除 3 个镜头」，不写「确定」）。

## 8. 动效与文案

### 动效

- 时长：`--g-dur-1` 120ms（悬停、按压）、`-2` 180ms（弹层出现）、`-3` 260ms（面板展开）。缓动统一 `--g-ease`，抽屉用 `--g-ease-drawer`。不使用弹跳。
- 只对 `transform` 和 `opacity` 做动画。
- 用户开启「减少动态效果」时，全部动效降为瞬时（已在 base.css 统一处理）。
- 同一视图第二次打开时不再播放入场动画。

### 文案

- 面向创作者说话，不出现内部术语：用「模型」，不用「执行者：API 模型」；用「在此配置图片模型」，不用 `GLINT_MEDIA_BASE_URL`。
- 主动语态、具体：写「保存失败：磁盘空间不足。请清理后重试。」，不写「哎呀，出错了！」。
- 不用感叹号、不用「赋能 / 一键搞定 / 极致」这类营销词。
- 按钮写动词加对象：「导出视频」「生成 3 个方案」。
- 所有界面文字都经过 `t()`（[ui/i18n.ts](../../apps/web/src/ui/i18n.ts)），不在组件里写死文案。

## 9. 自动门禁：`pnpm check:ui`

脚本 [scripts/check-ui.mjs](../../scripts/check-ui.mjs) 扫描 `apps/web/src`（测试文件除外），统计五类违规：

| 规则 | 含义 | 正确做法 |
|---|---|---|
| hexColor | 写死的 `#rrggbb` | 使用 `--g-*` 颜色令牌 |
| inlineStyle | JSX `style={{…}}` | 写 CSS 类；确实需要动态数值时，用 CSS 变量传入（`style={{"--w": …}}` 也会被计数，必要时用 `ui-allow` 说明理由） |
| rawFontSize | 不使用令牌的 `font-size` | `var(--g-fs-*)` |
| rawZIndex | 数字 `z-index` | `var(--g-z-*)` |
| important | `!important` | 调整选择器结构 |

- **棘轮规则**：[scripts/ui-baseline.json](../../scripts/ui-baseline.json) 记录 2026-11-02 已有的 1,149 处遗留违规。已有文件的计数只许减少，新文件必须为零。
- 修好遗留问题后，运行 `pnpm check:ui --update` 锁定进展；该命令拒绝任何增加。
- 确有必要的例外，在同一行写 `/* ui-allow: 理由 */`，评审者需要检查理由是否成立。
- CI 每个 PR 都会运行这个门禁。

## 10. 验收：每个 UI 改动必须完成

1. `pnpm check:ui`、`pnpm typecheck`、相关测试全部通过。
2. 运行 `pnpm --filter glint-web build`、`pnpm --filter glint-web serve`，再运行 `pnpm --filter glint-web exec tsx ../../scripts/capture-ui.ts http://127.0.0.1:4175/ outputs/ui-review/<WP-ID>`，得到 1440 / 1024 / 390 三种宽度下各主要路由的截图，以及深链接刷新后的截图。
3. 改动涉及颜色时，深色和浅色主题都要截图。
4. 在 PR 里附改动前后的对比截图，逐条对照下面的评分表自评；评审者（不同厂商的模型）复评。

### 评分表（每项 0–10，任何一项低于 8 打回）

| # | 维度 | 8 分标准 |
|---|---|---|
| 1 | 层级 | 一眼能看出主内容、主操作和当前位置；每个区域只有一个主按钮 |
| 2 | 一致性 | 只用令牌和 `ui/` 组件；与相邻页面的间距、字号、圆角一致 |
| 3 | 克制 | 强调色只出现在主操作、当前位置、选中和焦点；没有多余的边框和卡片 |
| 4 | 排版 | 中文行高、段宽、标点舒适；数字等宽；没有孤字、截断或溢出 |
| 5 | 状态完整 | 空、加载、错误、禁用（附原因）、悬停、按下、焦点、选中都有设计 |
| 6 | 交互 | 符合 §7 的十条规则；路由、离开保护、撤销都正确 |
| 7 | 响应式 | 三种宽度下没有裁切、重叠和多余的横向滚动；触屏目标 ≥ 44px |
| 8 | 无障碍 | 键盘可以完成全部操作；可访问名称正确；对比度达标；尊重减少动效设置 |
| 9 | 文案 | 面向创作者、动词加对象、没有内部术语、经过 `t()` |
| 10 | 性能 | 首屏 gzip 不超预算（`pnpm verify:budget`）；新的重型依赖按需加载 |

### 一票否决

- 新增硬编码颜色、内联样式、非令牌字号或层级（门禁会拦截）
- 引入第二个强调色，或使用紫蓝「AI 渐变」
- 页面本身出现整页滚动条，或同屏出现嵌套的多条滚动条
- 新视图没有路由，或刷新后丢失位置
- 绕过离开保护的导航
- 向用户展示环境变量名、堆栈或内部 ID
