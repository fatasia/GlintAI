# 角色资产

在分镜编辑器的「生成 → 角色资产与批准」里保存角色外观、素材库参考图和音色 ID，批准后可以把角色绑定到当前镜头。

1. 先将参考图片加入素材库，填写角色名称、外观和音色 ID，保存草稿。
2. 同步共享工程后点击「批准角色版本」。服务端将单张素材库图片按 SHA-256 保存为内容寻址副本，批准记录包含名称、版本、外观、音色、路径与摘要；未保存的修改不能批准。
3. 点击「绑定当前镜头并设置音色」。这会为当前镜头记录资产版本，并替换其旁白音色；其他镜头不受影响。
4. 如需恢复批准前的草稿，使用共享工程历史撤销；撤销会按历史顺序逐步进行。

批准后，共享会话的普通编辑不能更改或删除该角色资产，包括 CLI 和 Agent 事务；镜头本身仍可编辑。工程整体冻结或镜头锁定时不能绑定。生成时可显式选择已批准的角色参考图，发送前再次核对文件摘要；skills 网关和模型须声明支持图片参考。

旧工程中的批准仍然可读和绑定，但没有内容摘要的旧批准不能作为生成参考图。要升级，选择旧角色后创建新版本草稿、保存并重新批准，再在需要的镜头中逐一替换；旧版本和其他镜头保持不变。摘要用于核对发送内容，不是角色身份或批准来源的真实性证明；导入工程或通用会话可以包含外部构造的批准记录。生成期间参考文件变更不会自动使已生成候选失效，跨镜效果也取决于模型。
