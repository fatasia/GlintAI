# Web 与 PWA

```bash
pnpm web:serve
```

打开 http://localhost:4175。开发页面可用 `pnpm web`，但 API 与 PWA 验收使用前一个命令。

## 出片

1. 载入入门示例或粘贴资料，选择模板、主题与比例。
2. 编排分镜，修改画面文字和旁白，调整顺序，核对资料依据。
3. 选择配音与导出规格，生成视频，查看进度或下载 MP4。

资料默认离线编排；可显式选择模型编排，一句话想法始终需要服务端 `GLINT_LLM_*`。界面不接收密钥。模型输出结构不合格时最多追加一次修复请求。

编辑器支持 30 个文字场景、最近 30 次撤销/重做、JSON 导入导出、20 个最近项目。改写旁白会清除旧时长/字幕时间，重新估时。Ctrl/Cmd+S 保存项目；焦点不在文本输入框时，Ctrl/Cmd+Z、Shift+Z 或 Y 操作分镜历史。图片、HTML、自定义 Three 和外部音频项目继续使用 CLI，不从浏览器导入本机路径。

草稿默认无声、半尺寸。可选 Windows SAPI 离线配音、联网 Edge 配音，或服务端已配置参考录音的 Qwen 克隆；compact/balanced/quality 输出全尺寸。浏览器传入的是白名单选项，不能指定服务端执行命令或参考文件路径。编辑后的项目直接渲染，不重新生成其文案。

Qwen 服务配置为 `GLINT_QWEN_PYTHON`、`GLINT_QWEN_MODEL`、`GLINT_QWEN_REFERENCE` 和可选 `GLINT_QWEN_REFERENCE_TEXT`；这些是进程环境变量，`.env.example` 仅作示例，不会自动加载。模型安装和参考录音见[语音克隆](voice-cloning.md)。

单机队列默认同时运行一个任务，最多另排四个。请求 id 防重复；成功必须同时满足进程成功退出与有效 MP4 文件头。日志只展示已知阶段，不转发 provider 原始输出。取消在 Windows 使用 taskkill 终止整棵进程树，POSIX 使用独立进程组。

任务记录保存在 `apps/studio/out/.jobs/`，包含输入资料；浏览器保存最近任务 id、未确认提交的 requestId，并在 localStorage 自动保存资料正文、编辑项目及最近项目。资料保存在本机，不适合在公用设备保存敏感内容。存储失败时可导出项目 JSON。重启后未完成任务标为中断，不自动再次调用付费模型。元记录默认保留七天，输出 MP4 和来源不自动删除。下载支持 Range、HEAD 和 attachment。

提交前持久保存 requestId；即使 POST 回执丢失后关闭页面，刷新也会用只读 GET 查询对应任务，不自动再次调用模型。查询失败时暂停，用户可恢复查询或停止查询；停止查询不取消服务器任务。存储被禁用、任务记录过期或请求从未到达服务器时，仍需人工确认后重新提交。

## 离线与更新

生产构建生成 manifest、service worker 和安装入口（浏览器支持时）。初次只缓存轻量页面与首屏 JS，播放器、Three 与示例图片按需加载，用过后才能离线使用；不缓存 API、生成视频、用户资料或密钥。缓存过的示例可离线查看，生成和问答需要服务连接。新版本等待确认后重新加载，不自动打断工作。

PWA 不是 Electron 或原生 App。手机/macOS 安装、Safari/Firefox 行为要在对应设备验收；localhost 的测试不能替代真机测试。

## 理解检查

示例项目附作者指定的选择题。提交后显示正确项、解释、资料锚点，统计本机最近 1000 次作答及概念错题数。题目和答案不由模型临时编造，不自动记录观看或外传数据。次数包含重复作答，不等于独立观众数量，也不证明观众已经掌握概念。

## 部署范围

服务仅监听本机，校验 Host 与跨域写请求；没有互联网多租户认证、账单或配额系统。不要直接改监听地址对外发布。持久化输出和缓存可能包含私有资料，按本机文件管理策略处理。

## 画像目录

工作台支持搜索、查看指令及下载本机画像目录；HTTPS 目录和带摘要校验的 CLI 安装见[画像目录](personas.md)。这不改变 Web 服务仅监听本机的部署范围。

## 配音听评

工作台可载入本地参考录音与一到两段候选音频。A/B 顺序随机、文件名先隐藏，四项评分全部填写后才揭晓并导出 JSON。选文件不会上传音频，也不会自动打分；更换参考录音会清空旧评分。

## 首屏与静态资源

播放器与 Three 在点击预览时加载，加载失败由独立边界显示错误，不清空编辑区。生产构建包含 Brotli/gzip，服务端支持协商压缩、ETag、HEAD 与哈希文件长期缓存。数据接口和生成视频不使用公共缓存。
